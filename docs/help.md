# 飞账机器人 Help 使用手册

飞账是一个运行在飞书 / Lark 中的 AI 记账机器人。你可以直接用日常说话的方式告诉它一笔收支，也可以让它修改、撤销、汇总账目、管理月预算或生成消费报告。

> 在群聊中使用时，请先 `@飞账`；与机器人单聊时可直接发送。机器人回复“已记录”“已修改”“已撤销”或汇总结果后，才表示操作成功。

## 快速上手

| 你想做什么 | 可以这样说 |
| --- | --- |
| 记录支出 | `晚饭猪脚饭花了50元` |
| 记录收入 | `工资到账10000元` |
| 补记过去的账 | `昨天打车38.5元` |
| 修改最近一笔 | `上一笔改成45元` |
| 撤销最近一笔 | `撤销刚才那笔` |
| 查询支出 | `我今天花了多少钱` |
| 按分类查询 | `这个月餐饮花了多少` |
| 查询收入 | `这个月收入多少` |
| 设置分类预算 | `每月餐饮预算1500元` |
| 查看或取消预算 | `查看预算`、`取消餐饮预算` |
| 生成消费报告 | `生成这个月的消费图表` |
| 查看简要帮助 | `help`、`帮助` 或 `你会做什么` |

## 支持的功能

### 1. 自然语言记账

一条消息可以记录一笔支出或收入。建议至少说清楚“金额”和“用途/来源”：

- `早餐12元`
- `买日用品花了86.5`
- `房租支出2500元`
- `奖金到账2000元`

机器人会自动判断收支方向，并归入餐饮、交通、购物、居住、娱乐、医疗、教育、工资、奖金、其他等简短分类。回复示例：

```text
已记录支出 ¥50.00 · 餐饮
```

金额必须大于 0，最多保留两位小数。当前所有新账目使用管理员配置的统一默认币种，通常为人民币 CNY。

### 2. 识别日期和相对时间

可以在消息中带上日期或相对时间：

- `昨天午饭32元`
- `上周五打车45元`
- `8月1日收到稿费800元`

“今天”“昨天”“这个月”等表达按照机器人配置的时区解析，默认是 `Asia/Shanghai`。

### 3. 语音记账

直接发送飞书语音消息，或发送可转写的音频文件，例如说：

```text
今天晚饭花了五十元
```

机器人会先将语音转成文字，再按与文字消息相同的流程记账。背景噪声较大时，建议改用文字并明确说出金额。

### 4. 图片记账

可以直接发送：

- 小票照片
- 支付成功截图
- 包含明确金额和消费信息的账单截图

机器人会识别图片并尝试记录一笔账。收到回复后，请核对金额和分类是否正确。

> 当前一张图片只按一笔账处理，暂不支持把一张小票中的多个商品拆成多笔记录。

### 5. 修改最近一笔

可以修改自己最近一笔未撤销的记录，包括金额、收支方向、分类、备注或发生时间：

- `上一笔改成8元`
- `刚才那笔改成交通`
- `上一笔其实是收入`
- `上一笔是昨天发生的`

机器人只修改你明确指出的内容，其他字段保持不变。当前不支持按名称、日期或序号选择任意历史记录进行修改。

### 6. 撤销最近一笔

发送下面这类消息，可以撤销自己最近一笔未撤销的记录：

- `撤销刚才那笔`
- `删除上一笔`

撤销后的记录不会再计入汇总。当前不支持在飞书中恢复已撤销记录，也不支持指定任意历史记录撤销。

### 7. 查询和分类汇总

机器人可以按时间范围汇总支出或收入，并按分类列出金额：

- `我今天花了多少钱`
- `昨天支出多少`
- `这周花了多少`
- `这个月餐饮花了多少`
- `今年交通支出多少`
- `这个月收入多少`
- `上个月工资收入多少`

回复示例：

```text
合计支出 ¥75.00
• 餐饮：¥75.00
```

没有明确说“收入”时，汇总默认查询支出。汇总只包含当前用户、指定时间范围内且未撤销的记录。

### 8. 设置分类月预算

每个品类可以设置一个长期逐月沿用的预算：

- `每月餐饮预算1500元`
- `每月交通预算500元`
- `查看预算`
- `查看餐饮预算`
- `取消餐饮预算`

重复设置同一品类会更新额度。查看预算会显示本月已用金额、预算金额、使用比例和剩余额度；设置预算时也会返回当前进度，但不会立刻触发预警。

新增或修改本月支出后，某品类达到预算的 80% 时会提醒一次，达到或超过 100% 时再提醒一次。如果一笔消费直接超过预算，只显示超额提醒。同一品类的每个提醒档位在同一个自然月只发送一次，撤销支出不会重新开放已经发送过的提醒。

预算按机器人配置时区中的自然月统计，只计算当前用户、分类名称完全相同、未撤销的支出；收入和其他月份的记录不会触发本月提醒。预算设置会在以后每个月自动沿用。

### 9. 生成消费报告

机器人可以把最多 366 天的账目整理成消费报告卡片：

- `生成这个月的消费图表`
- `分析近30天消费`
- `生成上个月的消费报告`

报告包含支出分类占比、支出趋势、收入与支出对比，以及根据聚合数据生成的消费建议。92 天以内按日显示趋势，更长时间按月显示。建议服务只接收汇总金额，不会收到逐笔备注或用户身份。

## 使用规则和数据边界

- 每位飞书用户拥有独立账本；查询、修改和撤销不会操作其他人的记录。
- 机器人以飞书用户身份区分账本，不提供群共享账本。
- 同一个飞书事件会自动去重，避免因重复推送产生重复账目。
- 只有收到成功回复，才表示本次操作已经完成。
- AI 只负责理解消息并生成受限制的记账动作，不能直接访问数据库，也不能生成或执行 SQL。
- 账本保存在部署者自己的 PostgreSQL 数据库中；数据保留和备份策略由部署管理员负责。

## 当前暂不支持

- 一条消息同时新增多笔账
- 一张小票拆分为多个商品或多笔记录
- 查看逐笔明细或账单列表
- 搜索、修改或删除指定的任意历史记录
- 恢复已撤销的记录
- 用户自定义分类、个人币种或个人时区
- 数据导出、单月例外预算、自定义预警比例、账户余额和群共享账本
- 附件、视频、表情等非文字、非音频、非图片消息

## 常见问题

### 为什么机器人没有回复？

在群聊中先确认已经 `@飞账`。如果仍无回复，可能是机器人未加入群、应用权限或事件订阅未配置完成，或者服务暂时离线，请联系部署管理员。

### 为什么提示“处理失败了”？

可以稍后重试，或换成更明确的说法。推荐按下面的顺序表达：

```text
时间 + 用途/来源 + 金额 + 收入或支出（需要时）
```

例如：`昨天晚饭支出50元`、`今天工资收入10000元`。

### 为什么金额或分类识别错了？

发送 `上一笔改成……` 立即修正。例如：`上一笔改成45元，分类改成交通`。图片和语音记账后尤其建议核对机器人的确认回复。

### 为什么汇总结果为空？

检查查询的时间范围、收支方向和分类是否正确。也可以先扩大范围，例如把 `今天餐饮花了多少` 改成 `这个月花了多少`。

### 怎样查看机器人能做什么？

发送 `help`、`帮助` 或 `你会做什么`，机器人会返回简要示例；完整说明以本文档为准。

## 一句话模板

不确定怎么说时，直接套用下面的模板：

```text
记支出：今天 [用途] 花了 [金额] 元
记收入：今天收到 [来源] [金额] 元
改上一笔：上一笔改成 [新内容]
撤销上一笔：撤销刚才那笔
查支出：[时间范围] [分类，可省略] 花了多少
查收入：[时间范围] [分类，可省略] 收入多少
设预算：每月 [分类] 预算 [金额] 元
看预算：查看预算
取消预算：取消 [分类] 预算
```
